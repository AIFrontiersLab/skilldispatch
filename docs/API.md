# Skilldispatch API

## Base URL

Local default: `http://127.0.0.1:8000`

## Endpoints

### `GET /health`

Returns process health, adapter status, and mode flags.

### `POST /pivot`

Translate legacy skills into ranked AI-adjacent roles and a phased roadmap.

**Request**

```json
{
  "skills": "data entry, customer support",
  "experience_years": 3
}
```

**Response highlights**

- `original_skills`
- `target_roles`
- `roadmap[]` with phase/action/priority/hours
- `estimated_time_weeks`
- `normalized_skills[]`
- `role_matches[]`
- `diagnostics`

### `GET /roles?limit=25`

Ranked slice of the role catalog with demand and family metadata.

### `GET /roles/{role_title}/market`

Stub labor-market observation for a role title.

### `GET /ontology/stats`

Coverage counters for legacy skills, aliases, and catalog roles.

## Headers

- `X-Request-ID` — echoed/generated by middleware
- `X-Process-Time-Ms` — request timing

## Errors

- `400` empty/unusable skills
- `422` schema validation failures (e.g., negative years)
